# Análise de Strings com JavaScript

Projeto desenvolvido durante meus estudos de JavaScript para praticar manipulação de strings e interação com o DOM.

## Funcionalidades

- Exibe o nome informado pelo usuário
- Conta a quantidade de caracteres
- Mostra a segunda letra do nome
- Busca caracteres utilizando indexOf()
- Busca a última ocorrência utilizando lastIndexOf()
- Obtém as últimas letras utilizando slice()
- Divide palavras utilizando split()
- Converte texto para maiúsculas e minúsculas

## Tecnologias

- HTML5
- JavaScript

## Objetivo

Praticar métodos de strings e manipulação do DOM utilizando JavaScript puro.
